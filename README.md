# 🌱 Spring Boot Essentials

> Repositório de estudos sobre Spring Boot desenvolvido durante meu aprendizado de conceitos do framework.

## 📖 Sobre

Este repositório reúne um pequeno projeto desenvolvido para praticar os principais conceitos do ecossistema **Spring Boot**.

O objetivo não é criar uma aplicação pronta para produção, mas sim servir como um laboratório para experimentar funcionalidades, entender boas práticas e consolidar conhecimentos adquiridos.

## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/EriikGabriel/spring-boot-essentials.git
```

Entre na pasta:

```bash
cd spring-boot-essentials
```

Execute utilizando o Maven:

```bash
./mvnw spring-boot:run
```

Ou abra o projeto em sua IDE de preferência e execute a classe principal da aplicação.
